\# KI-COMPILER 2026



A custom compiler developed as an academic project for the \*\*Compiler Technology\*\* course at \*\*Nanjing Tech University\*\*.



\## 📌 Project Overview



\*\*KI-COMPILER 2026\*\* is a Windows Forms-based compiler application developed using \*\*C# and .NET\*\*.



The project demonstrates fundamental compiler concepts including lexical analysis, tokenization, parsing, grammar-based processing, and compiler-related analysis through a graphical user interface.



\## ✨ Features



\- 🔤 Lexical Analysis

\- 🌳 Syntax Analysis and Parsing

\- 🔢 Token Counter

\- 🖥️ Graphical User Interface

\- 🧹 Clear Function

\- ℹ️ About Section

\- 📊 Token Processing

\- ⚙️ Custom Grammar Processing



\## 🛠️ Technologies Used
